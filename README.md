# 🚀 JetPack Compose Tutorial

A comprehensive collection of **Jetpack Compose** examples covering UI components, layouts, state management, navigation, animations, and modern Android development best practices.

> Perfect for beginners and experienced Android developers who want to master Jetpack Compose through practical examples.

- ✅ Basic Compose UI

## 🚀 Getting Started

### Prerequisites

- Android Studio (Latest Version)
- JDK 17+
- Android SDK
- Kotlin

### Clone Repository

```bash
git clone https://github.com/kangondiaravind/JetPackComposeTutorial.git
```

Open the project in **Android Studio**, sync Gradle, and run the app.
